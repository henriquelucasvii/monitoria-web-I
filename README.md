## Objetivo do repositório

Este repositório foi criado para apoiar os **alunos da disciplina de Programação WEB I** durante os encontros de monitoria. Aqui você encontra exercícios propostos pelo professor **já resolvidos e comentados**, com o objetivo de:

- Reforçar os conceitos vistos em sala de aula;
- Servir como material de consulta para estudo individual;
- Ajudar a destravar dúvidas comuns sobre **HTML, CSS e JavaScript**;
- Mostrar diferentes formas de resolver um mesmo problema, incentivando o raciocínio lógico e boas práticas de front-end.

## Como usar este repositório

1. Clone o repositório na sua máquina:
   ```bash
   git init
   git clone https://github.com/seu-usuario/monitoria-web1.git
   ```
2. Navegue até a pasta do exercício que deseja estudar.
3. Abra o arquivo `.html` no navegador para ver o resultado.
4. Leia os comentários no código ou o arquivo explicativo da pasta para entender o passo a passo da solução.
5. Tente refazer o exercício sozinho antes de olhar a resposta.
